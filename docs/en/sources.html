Sources

Source data, the notation, earlier work

1. Five source datasets

All are published under CC BY 4.0. They were obtained at pinned releases and commits; the SHA-256 hashes of the files used are in data/SOURCES.md in the repository. The source data themselves are not redistributed here. When you use this table, please credit these datasets as well. The notes accompanying WALS, Lexibank, Glottolog and ABVD ask that the release used also be cited by its DOI. This edition does not give those DOIs; when citing, please check the release page of each repository. The "version used" in the table records how the files were obtained; that the files received are identical to that release cannot be proven from the material in this repository alone. The files actually used are fixed by their hashes.

Lexibank aggregates 134 wordlist datasets. The first part of the lexibank_variety column names the dataset. Citations for each are in Lexibank's contributions.csv. This repository does not carry the wordlists, only the proportions counted from them.

PHOIBLE inventories come from several sources (the sources column: SPA, UPSID, AA, PH, GM, RA, SAPHON, UZ, EA, ER). Tone counts were read only from inventories of the six sources that record tone (SPA, AA, PH, GM, RA, UZ).

2. The notation

  • Sejong notation, edition 3.2 — https://bowonkwon.github.io/Legal-Language-Handbooks/sejong/ (in Korean). The list of shapes, the rules for finals and side dots, and the per-language mapping tables with their sources are there. The letter-slot tables inside the computation tool are a classification built from the common rows of the mapping table published by that site (data/mapping.csv, CC BY 4.0): where a shape depends on context one is chosen, and series written by rule and the processing tables are added.

  • Havens, Emily Paige. 2024. A Phonological Sketch of Ciacia, with Implications for Orthography. MA thesis, Dallas International University. — Consonant inventory of Cia-Cia, Bahari dialect (Table 9, p. 44), vowels, and the description of stress (p. 60).

5. Earlier work

A study that puts a number on how far a language can be written in Hangul already exists.

  • Jeon, Kwang-jin [전광진]. 2009. 타이완 원주민 언어에 대한 한글 서사법 개발 연구 [A study on developing Hangul writing systems for the indigenous languages of Taiwan — title translated here]. 中語中文學 45: 351–388. 韓國中語中文學會.

The paper gives a "Hangul writing adaptability" figure for ten indigenous languages of Taiwan: for initial consonants, final consonants and vowels, the proportion of phonemes that can be written in Hangul under four stated principles, plus syllable structure (80% where there is a constraint such as consonant clusters), averaged as a simple mean of the four (p. 360, note 15). The ten languages range from 66% to 88%, and the table's mean cell reads 71% (p. 382, Table 2; averaging the ten values again gives 77.9%).

It differs from this table in three ways.

Jeon 2009 This table
What is counted The proportion of phonemes close enough in sound to a Hangul letter to be written The number of distinct sounds listed in an inventory that merge into a shared slot in this classification
Syllables 80% if the syllable types pose a constraint, 100% otherwise The share of syllables in a wordlist that fit the frame
Aggregation Mean of four values, then an order Each layer reported separately, no order

Because different things are counted, the two sets of values cannot be compared to say that one is right.

A later paper by the same author was also consulted.

  • Jeon, Kwang-jin [전광진]. 2018. 타이완 원주민족 이따알어 한글 서사 방안 [Hangeul Writing System for Atayal Language in Taiwan — the paper's own English title]. 中語中文學 74: 83–116.
